# App-Teste em React

Conversão do projeto original em HTML, CSS e JavaScript para React com Vite.

## Rodar localmente

```bash
npm install
npm run dev
```

Depois abra o endereço mostrado pelo Vite no terminal.

## Gerar versão de produção

```bash
npm run build
```

Os arquivos finais serão gerados na pasta `dist`.
